# Reaction Test Game

A simple Pygame program that tests your reaction time.

## How to Play

1. Run the program using Python:
   ```
   python reaction_test.py
   ```

2. Press the spacebar to start the test
3. Wait for the "GO!!!" prompt to appear
4. Press the spacebar as quickly as possible when you see "GO!!!"
5. Your reaction time will be displayed, along with your best time
6. Press spacebar again to try to improve your score

## Requirements

- Python 3.x
- Pygame

To install Pygame:
```
pip install pygame
```

## Features

- Visual spacebar indicator
- Trophy display for your best reaction time
- Random waiting periods to prevent pattern learning
- Simple and intuitive interface
